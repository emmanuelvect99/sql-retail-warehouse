## 📌 Overview

**SQL Retail Data Warehouse** is an end-to-end relational data warehouse and business intelligence pipeline engineered using **SQLite**, **Python (Pandas)**, and **SQL Window Functions**.

---

## 📐 Data Architecture & Schema Design

The Data Warehouse follows a **Star Schema** architecture composed of two dimension tables (`customers`, `products`) and one central fact table (`sales`).
